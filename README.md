
# مشروع أكاديمية تعليم السياقة

هذا المشروع هو تطبيق ويب متكامل لإدارة مدرسة تعليم سياقة، تم بناؤه باستخدام Next.js و Firebase. يوفر التطبيق واجهة عامة للزوار، ولوحة تحكم قوية للمسؤولين، وبوابة خاصة للمتدربين لمتابعة تقدمهم.

## ✨ المميزات الرئيسية

- **واجهة عامة احترافية:** صفحات ديناميكية لعرض الدورات، الأسعار، معلومات عن المدرسة، ومعرض صور.
- **لوحة تحكم للمسؤول (Admin Dashboard):**
  - إدارة كاملة للمتدربين (إضافة، تعديل، حذف، فلترة).
  - إدارة مالية لتتبع مدفوعات المتدربين.
  - إدارة محتوى الموقع (الصفحة الرئيسية، من نحن، التذييل).
  - تخصيص كامل لمظهر الموقع (ألوان، خطوط، قوالب جاهزة).
  - إدارة الدورات، أصناف الرخص، الامتحانات، الأسئلة الشائعة، وآراء الطلاب.
- **لوحة تحكم للمتدرب (Trainee Dashboard):**
  - عرض المعلومات الشخصية وإمكانية تعديلها.
  - تتبع التقدم في مسار الامتحانات.
  - عرض الوضع المالي والمدفوعات.
  - استلام إعلانات من إدارة المدرسة.
- **نظام مصادقة آمن:** تسجيل الدخول للمستخدمين والمدراء باستخدام Firebase Authentication.
- **قاعدة بيانات Real-time:** استخدام Firestore لتخزين البيانات وتحديثها بشكل فوري.

## 🚀 التقنيات المستخدمة

- **Next.js:** إطار عمل React لبناء تطبيقات الويب الحديثة.
- **Firebase:** منصة متكاملة تشمل:
  - **Firestore:** قاعدة بيانات NoSQL لتخزين البيانات.
  - **Firebase Authentication:** لإدارة المستخدمين وتسجيل الدخول.
  - **Firebase Storage:** لتخزين الملفات مثل الصور.
  - **Firebase Functions:** لتنفيذ منطق برمجي في الخلفية (مثل إنشاء المستخدمين).
- **TypeScript:** لإضافة أنواع للمتغيرات وتحسين جودة الكود.
- **Tailwind CSS:** لتصميم واجهات المستخدم بسرعة.
- **Shadcn/ui:** مجموعة من مكونات الواجهة الجاهزة والقابلة للتخصيص.
- **Zod:** للتحقق من صحة البيانات في النماذج.
- **React Hook Form:** لإدارة نماذج الإدخال بفعالية.

## 📁 هيكل المشروع وشرح الملفات

فيما يلي شرح للمجلدات والملفات الرئيسية في المشروع لمساعدتك على فهم بنيته.

### 📂 `/` (المجلد الرئيسي)

- **`next.config.ts`**: ملف الإعدادات الخاص بـ Next.js.
- **`tailwind.config.ts`**: ملف إعدادات Tailwind CSS لتخصيص التصميم.
- **`package.json`**: يسرد جميع الحزم والمكتبات التي يعتمد عليها المشروع، بالإضافة إلى الأوامر (scripts) لتشغيل وبناء المشروع.
- **`firebase.json`**: ملف إعدادات Firebase الذي يحدد قواعد الاستضافة (Hosting) والدوال (Functions).
- **`firestore.rules`**: **مهم جدًا.** ملف قواعد الأمان لقاعدة بيانات Firestore. يحدد من يمكنه قراءة أو كتابة البيانات في كل جزء من قاعدة البيانات.
- **`storage.rules`**: ملف قواعد الأمان لمساحة تخزين Firebase Storage، يحدد من يمكنه رفع أو قراءة الملفات.
- **`.gitignore`**: يخبر Git بالملفات والمجلدات التي يجب تجاهلها (مثل `node_modules`).

### 📂 `src/app/` (مجلد التطبيق الرئيسي)

هذا هو قلب التطبيق ويستخدم نظام التوجيه (App Router) من Next.js.

- **`layout.tsx`**: **الملف الأب لجميع الصفحات.** يحتوي على الهيكل الأساسي لصفحة HTML، ويقوم بتضمين الهيدر (Header) والفوتر (Footer) وتوفير سياق المصادقة (AuthProvider) لجميع أجزاء التطبيق.
- **`globals.css`**: ملف CSS الرئيسي الذي يحتوي على إعدادات المظهر (الألوان والخطوط) من ShadCN ومتغيرات CSS العامة.
- **`page.tsx`**: الصفحة الرئيسية للموقع التي يراها الزوار (`/`).

#### 📄 الصفحات العامة (Public Pages)

- **`/about/page.tsx`**: صفحة "من نحن".
- **`/courses/page.tsx`**: صفحة عرض جميع الدورات.
- **`/pricing/page.tsx`**: صفحة عرض خطط الأسعار.
- **`/faq/page.tsx`**: صفحة الأسئلة الشائعة.
- **`/traffic-signs/page.tsx`**: صفحة عرض إشارات المرور.
- **`/contact/page.tsx`**: صفحة "اتصل بنا".
- **`/gallery/page.tsx`**: صفحة معرض الصور.

#### 🚪 صفحات الدخول والتسجيل (Auth Pages)

- **`/login/page.tsx`**: صفحة تسجيل الدخول للمدراء والمتدربين.
- **`/register/page.tsx`**: صفحة تسجيل متدرب جديد.
- **`/submit-testimonial/page.tsx`**: صفحة تسمح للمستخدمين المسجلين بإرسال آرائهم.

#### 🎛️ لوحة تحكم المدير (`/admin/`)

- **`layout.tsx`**: الهيكل الخاص بصفحات المدير، يتضمن الشريط الجانبي (Sidebar) للتنقل.
- **`page.tsx`**: الصفحة الرئيسية للوحة تحكم المدير، تعرض إحصائيات عامة.
- **`/appearance/page.tsx`**: **صفحة تخصيص المظهر.** هنا يمكن للمدير تغيير الخطوط، الألوان، واختيار قوالب تصميم جاهزة للموقع.
- **`/content/*`**: صفحات لإدارة محتوى الصفحات العامة (الرئيسية، من نحن، التذييل).
- **`/trainees/page.tsx`**: صفحة إدارة جميع المتدربين.
- **`/trainees/[id]/page.tsx`**: صفحة عرض ملف متدرب معين وتتبع تقدمه في الامتحانات.
- **`/financials/page.tsx`**: صفحة الإدارة المالية وتتبع مدفوعات المتدربين.
- **`/courses/page.tsx`**: صفحة إدارة الدورات التدريبية.
- **`/exams/page.tsx`**: صفحة إدارة مسار الامتحانات.
- **`/traffic-signs/page.tsx`**: صفحة إدارة إشارات المرور وفئاتها.

#### 👤 لوحة تحكم المتدرب (`/dashboard/`)

- **`page.tsx`**: الصفحة الرئيسية للمتدرب، تعرض نظرة عامة على تقدمه وإشعارات المدرسة.
- **`/profile/page.tsx`**: صفحة تتيح للمتدرب تعديل معلوماته الشخصية وتغيير كلمة المرور.

### 📂 `src/components/` (المكونات)

- **`/ui/`**: مكونات واجهة المستخدم الأساسية من Shadcn/ui (مثل `Button`, `Card`, `Input`).
- **`/layout/`**: مكونات الهيكل العام للموقع مثل `header.tsx`, `footer.tsx`, `logo.tsx`.
- **`/home/`**: المكونات المستخدمة فقط في الصفحة الرئيسية (مثل `hero-section.tsx`, `features-section.tsx`).
- **`/admin/`**: مكونات خاصة بلوحة تحكم المدير (مثل نماذج الإضافة والتعديل، الجداول، المخططات البيانية).
- **`/trainee/`**: مكونات خاصة بلوحة تحكم المتدرب (مثل `trainee-exam-progress.tsx`).

### 📂 `src/lib/` (المكتبات والبيانات)

- **`firebase.ts`**: ملف تهيئة وإعداد اتصال Firebase.
- **`data.ts`**: يحتوي على تعريفات الأنواع (Types) المستخدمة في المشروع (مثل `Course`, `FAQ`) وبيانات ثابتة.
- **`data-access.ts`**: يحتوي على دوال لجلب البيانات من Firestore للصفحات العامة.
- **`utils.ts`**: دوال مساعدة، وأهمها دالة `cn` لدمج أسماء الفئات في Tailwind CSS.
- **`icons.ts`**: يسجل الأيقونات المتاحة للاختيار الديناميكي في لوحة التحكم.

### 📂 `src/hooks/` (Hooks)

- **`use-auth.tsx`**: **Hook محوري.** يدير حالة تسجيل دخول المستخدم، ويجلب بياناته من Firestore، ويوفرها لجميع مكونات التطبيق.
- **`use-toast.ts`**: Hook لعرض إشعارات مؤقتة (Toasts) للمستخدم.

### 📂 `functions/` (الدوال السحابية)

- **`index.js`**: يحتوي على منطق برمجي يعمل في الخادم (Backend) عبر Firebase Functions.
  - **`createTrainee`**: دالة آمنة لإنشاء حساب مستخدم جديد مع الصلاحيات الصحيحة في Auth و Firestore.
  - **`updateTraineeProfile`**: دالة آمنة تسمح للمتدرب بتحديث بياناته الشخصية.
