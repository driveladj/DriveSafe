# مشروع أكاديمية تعليم السياقة (نسخة الواجهة الأمامية فقط)  Versio 1.0.1

هذه نسخة احتياطية للواجهة الأمامية (Frontend) من مشروع أكاديمية تعليم السياقة. تم فصل هذه النسخة عن قاعدة البيانات (Firebase) وجميع الخدمات الخلفية.

## ✨ الغرض من هذه النسخة

- **للعرض والأرشفة:** يمكن تشغيل هذا المشروع محليًا لعرض تصميم وتفاعل واجهات المستخدم دون الحاجة إلى أي إعدادات خلفية.
- **نسخة احتياطية:** تعتبر نسخة آمنة من كود الواجهة الأمامية.
- **غير تفاعلية:** جميع الوظائف التي تتطلب اتصالًا بالخادم (مثل تسجيل الدخول، التسجيل، حفظ البيانات) تم تعطيلها. البيانات المعروضة هي بيانات ثابتة ومضمنة في الكود.

## 🚀 التقنيات المستخدمة

- **Next.js:** إطار عمل React لبناء تطبيقات الويب الحديثة.
- **TypeScript:** لإضافة أنواع للمتغيرات وتحسين جودة الكود.
- **Tailwind CSS:** لتصميم واجهات المستخدم بسرعة.
- **Shadcn/ui:** مجموعة من مكونات الواجهة الجاهزة والقابلة للتخصيص.

---

## 📁 ملاحظات حول الهيكل

- **لا يوجد اتصال بـ Firebase:** تم تعطيل جميع الاتصالات بقاعدة البيانات في `src/lib/firebase.ts`.
- **بيانات ثابتة:** الملفات الموجودة في `src/lib/data.ts` و `src/lib/data-access.ts` تحتوي الآن على بيانات ثابتة (Static Data) بدلاً من جلبها من قاعدة البيانات.
- **الوظائف معطلة:** تم تعطيل الوظائف التي كانت تتفاعل مع Firebase، مثل نماذج التسجيل وتسجيل الدخول في صفحات مثل `register` و `login`.
