# **App Name**: DriveSafe Academy

## Core Features:

- Customizable Homepage: Admin-adjustable elements including school name/logo, welcome message, CTA button, image gallery, and feature highlights, controlling visibility and content.
- Course Management: Manage driving course types (e.g., B license, motorcycle), lesson details, duration, and add/edit/delete courses via admin panel.
- Pricing Configuration: Create, modify, and remove pricing tiers. Customize offer names, license types, pricing, lesson counts, features, CTA button and enable/disable offers with visual customization for highlighting best deals.
- Trainee Registration System: Collect trainee info, including name, birthdate, gender, license type, and phone number login with password, managed via admin panel.
- Dynamic Banner Management: Publish and manage promotional banners or temporary offers with title, description, image, CTA button, start/end dates, and status control.
- FAQ Manager: Admin interface for adding, modifying, deleting, and showing/hiding questions and answers.
- AI-Powered Curriculum Tool: An AI tool that recommends customized curriculum options (lesson plans, exercises) based on student progress tracking. Admin may then activate those plans and send to a student.

## Style Guidelines:

- Primary color: Deep blue (#30475E), inspired by the professional and trustworthy nature of driving instruction. Dark Blue gives feelings of reliability and competence.
- Background color: Very light blue-gray (#D6DDE3). This provides a clean and professional backdrop.
- Accent color: Teal (#26A69A), offering a contrasting color to draw attention to calls to action and important information.
- Body font: 'PT Sans' (sans-serif) offers a modern yet approachable feel for the website’s main content.
- Headline font: 'Playfair' (serif), brings an elegant and high-end feel, perfect for titles.
- Use modern, flat icons that relate to driving and learning.
- Maintain a clean, structured layout with clear sections and visual hierarchy.
- Subtle transitions and animations to enhance user experience without being distracting.
